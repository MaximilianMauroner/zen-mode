# Product direction

Max made these decisions on 18 November 2026. They hold until Max changes them.

## Two users

Zen Mode serves two users with the same features:

- A parent sets up a device for a child. The parent sets the limits, and the
  child cannot change them in Zen Mode.
- A power user sets up their own device. They limit YouTube, X, and Instagram
  without deleting the apps or turning off the algorithm completely.

## Platforms

Zen Mode must work on Android phones and tablets, iPhone, and iPad. YouTube, X,
and Instagram come first.

## Limits

Each visit to a guarded app starts with a stop time that the user picks. A
daily cap limits all visits in one day. Past the limit, Zen Mode blocks the app.

The idea comes from ClockwiseTV: <https://clockwisetv.com/>.

## Settings lock

The person who sets up the device must be able to pick one of two locks: a
passcode, or a time lock such as 7 days. Both users can pick either lock.

## Removal protection

Zen Mode does not stop a child from removing it. Kids setup points the parent to
the operating system's own controls:

- On Android, Google Family Link.
- On iOS, a Screen Time passcode with app deletion blocked.

On iOS, Zen Mode uses `.individual` Family Controls authorization only. It does
not use `.child`.
