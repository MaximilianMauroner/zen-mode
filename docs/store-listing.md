### Short description

Set clear limits for feeds and apps on Android.

### Full description

Zen Mode helps you set boundaries for attention on Android.

Set one rule for each launchable app:

- a daily budget that sends you Home when it runs out;
- a timed visit with downtime between visits; or
- a rolling allowance that refills as older use leaves its window.

Set feed rules in grouped controls for YouTube, Instagram, and X:

- YouTube Shorts: allow one Short per visit, then block scrolling to another;
- Instagram Reels: pause before Reels and set a viewing window;
- Instagram Home: take a break after a chosen amount of viewing;
- Instagram Explore: block Explore or leave it available;
- X Home: take breaks after a chosen interval; and
- X videos: allow one video per visit, then block video scrolling.

Zen Mode uses Android Accessibility access to identify supported screens and
apply your rules. Complete the in-app observation setup before feed protection
starts. Detection is limited to supported accessibility layouts, so an update
to YouTube, Instagram, or X can change what is recognized. Protection stays
off until you enable it.

The feed protections require Android Accessibility access. YouTube, Instagram,
X, and Android are third-party products and are not affiliated with Zen Mode.

## Required listing assets

- A 512 × 512 app icon from the final artwork.
- A 1024 × 500 feature graphic. This is required to publish the store listing.
- Final phone screenshots from the signed Android candidate, with personal
  account data and notifications removed.
- An optional promo video, if the owner chooses to provide one.
- Use `lab4code.dev@gmail.com` as the support email. Final support and privacy
  policy URLs still require owner input.
- Final category, content rating, target audience, countries, and pricing.

See Google's [preview asset requirements](https://support.google.com/googleplay/android-developer/answer/9866151)
for the current Play Console fields and file rules.
